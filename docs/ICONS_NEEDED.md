# Ícones e marcas necessários

Inventário baseado nas chamadas da UI e nos dados de ações/construções. Uma linha por ID visual, agrupada por prioridade. Os tamanhos consolidam os valores de `icon_rect` e dos botões existentes; quando o mesmo ícone aparece em vários componentes, a linha informa a faixa usada. Glifos geométricos e letras do projeto são os fallbacks atuais.

**P1**: HUD e partida. **P2**: menus e painéis. **P3**: itens raros ou envio separado.

| Tecla | Ação/construção | ID do ícone |
| --- | --- | --- |
| `1` | Cidade | `city` |
| `2` | Porto | `port` |
| `3` | Fábrica | `factory` |
| `4` | Defesa | `defense` |
| `5` | SAM | `sam` |
| `6` | Silo | `silo` |
| `7` | Navio de guerra | `warship` |
| `8` | Bomba atômica | `atom` |
| `9` | Bomba de hidrogênio | `hydrogen` |

As ações do Arsenal são adicionadas à faixa conforme o desbloqueio e não têm uma tecla numérica fixa: `artillery`, `airfield`, `railgun`, `mega`, `scatter`, `airstrike`, `slug` e `reinforce`.

A busca `rg -n 'Icons\.get' src/client src/shared --glob '*.luau'` lista quatro chamadas de consumo em `Main.luau`, `AdminPanel.luau`, `UITheme.luau` e `Widgets.luau`, além da definição em `src/shared/UI/Icons.luau`. O HUD, abas, `Widgets.Icon` e os ImageLabels do Arsenal/loja consultam a mesma tabela de slots. A tabela cobre os 50 nomes de `ICON_GLYPHS`, os nomes legados de `Icons.luau`, os usos estáticos de `icon_rect/set_icon` e as ações dinâmicas de `UIRules`, `Defs` e `Arsenal`. Os aliases (`groups`, `public`, `storefront` e carteira) usam o slot canônico. `calm` em `CrateButton.luau` é estado, não ícone. `game_icon` é uma imagem de experiência para upload separado, não chamada em runtime.
