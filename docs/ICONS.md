# Ícones do DomWorld

Os fallbacks atuais são desenhados pela UI do projeto. O inventário das imagens que podem ser escolhidas depois está em `docs/ICONS_NEEDED.md`; as regras e créditos ficam em `docs/ICON_SOURCING_RULES.md` e `docs/ICON_CREDITS.md`.

O atlas permanece desligado até receber imagens originais com crédito preenchido e um ID de upload próprio. Use `docs/ICONS_UPLOAD.md` para gerar e enviar o atlas.
